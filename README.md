# 📝 To-do List Web Application

A simple and user-friendly To-do List application designed to help users organize their daily tasks and improve productivity. It features a clean interface with a beautiful green-to-yellow gradient background.

## ✨ Features

- ➕ Add new tasks easily.
- 🎨 Attractive gradient background.
- 📱 Clean and user-friendly interface.
- ⚡ Simple and lightweight application.
- ✅ Easy task management.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, and gradient background.
- **JavaScript** – Task management and interactive functionality.

## 📸 Preview

The application features a centered white card with a task input field and an Add button, displayed against a green-to-yellow gradient background.
